# Privacy Policy — Helium Update Checker

**Last updated:** 2026-06-03

Helium Update Checker does not collect, store, transmit, or share any
personal or user data.

The extension only:

- Reads publicly available release and commit information from the official
  Helium GitHub repositories (`helium-windows`, `helium-macos`,
  `helium-linux`) via the GitHub API (`api.github.com`).
- Stores the most recently seen release tag/commit locally in your browser
  (`chrome.storage.local`) solely to detect when a new update is available.
  This information never leaves your device.

No analytics, tracking, advertising, or third-party data sharing of any kind
is performed. No data is sold or transferred to anyone.
